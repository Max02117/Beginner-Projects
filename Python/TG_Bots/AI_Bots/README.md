# 🤖 AI Bots  
Учебные Telegram боты разной сложности с интеграцией ИИ - от простого эхо-бота до AI-ассистента.  

## 🎯 **Назначение файлов:**  
- **`AI_Bot.py`** - Сам Telegram бот.  
- `ai_standalone.py` - Тестовая версия AI для локального запуска без Telegram.  
- `requirements.txt` - Список библиотек.  
- `.env.example` - Пример файла хранящий токен.  

## 📁 ****Проекты:**  
- **AI_Bot-1.0** - Простой эхо-бот.  
- **AI_Bot-2.0** - Бот с интеграцией gpt-4o-mini.  
- **AI_Bot-3.0** - Изменена модель на gpt-4; добавлены кнопки для выбора роли; Добавлена память.  
- **AI_Bot-4.0** - Улучшена память; добавлены текстовые команды для управлением темой и ролью.  
- **AI_Bot-5.0** – Добавлено переключение версии модели; выбор предустановленных ролей и ввод собственной роли; per-user состояние (history, prompt, waiting_custom) с очисткой истории при смене роли.
